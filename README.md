# Cyber Core — Mac / Google Chrome

## 起動方法
1. Google Chrome と Node.js LTS をインストールします: https://nodejs.org/
2. このフォルダ内の `起動.command` をFinderからダブルクリックします。
3. 初回起動時は `npm install` が実行されます（インターネット接続が必要です）。
4. ゲームは Google Chrome で `http://127.0.0.1:3000` に開きます。
5. 終了するには、起動したターミナルで `Control + C` を押します。

このアプリはReact/Vite製のため、`index.html` を直接開くのではなく、起動スクリプト経由でローカルサーバーを立ち上げてください。

### 近接の手応え（全INFIGHT武器共通）

- **刃の軌跡**: 刃先を毎フレーム追跡して描く斬光リボン（`src/utils/weaponTrail.ts`）。実際の振りの軌道どおりに尾を引く。
- **斬光の描画アニメーション**: 斬撃エフェクトは振り抜く向きに走って描かれ、尾から溶けて消える。各層の不透明度を保ったままフェードする。
- **ヒットストップ**: 命中の瞬間にゲーム時間をごく短く止める（段が上がるほど・重い武器ほど長い）。視点操作は止まらない。
- **カメラロール**: 振りの向きに合わせて視界が少し傾き、ばねで戻る。
- **溜め**: 武器ごとの溜めの構え＋光の収束エフェクト、満タンで光条が弾ける。
- エフェクト用の点光源は固定数のプールを使い回す（ライト数の増減によるシェーダ再コンパイルのカクつきを防止）。

### 攻撃操作

- 左クリック長押しで、振りが終わるたびに次の段が自動で出るので3段攻撃まで出し切れます（連打でも可）。
- 3段攻撃の後、および右＋左クリックの技（Sweep / Leap Slam / Thunder Thrust / Ripper Rush）の後のクールタイムは **0.5秒**。
- RAVAGER-09 は段コンボではなく、押している間ずっと削り続けます（離すと終了。短く押しても振り下ろしの一撃は出ます）。

## 銃火器・重火器の調整（INFIGHT以外）

- **ファイアレート制限**: セミオート銃もステータスの `fireRate` 以上の連打はできません。
- **クリティカル**: `critRate` に応じて1発ごとに判定し、ダメージ1.75倍（黄色の `CRITICAL!` 表示）。
- **射程**: `range` で弾の飛距離が決まります。SMG・ショットガンは近距離で大きく減衰し、ハンドガン・ARは中距離から緩やかに減衰。スナイパーと重火器は減衰なし。

## リロードアニメーション

全銃種のリロードを「本物のFPS」風に作り直しました（`src/utils/weaponReload.ts` / `src/utils/pistolReload.ts`）。左手が実際に作業し、機構音とともに各動作で銃が跳ね、最後に小さな決めの動きを入れて構えに戻ります。

| 系統 | 動き |
|---|---|
| ハンドガン | 銃を内側へ大きく傾けて手首のスナップで空マガジンを振り落とす → 新しいマガジンを差し込み掌で叩き込む → 空からのリロードは上からスライドを引いて離す（弾が残っていれば軽く構え直す） |
| リボルバー | シリンダーを振り出し、銃口を跳ね上げて薬莢を排出（実際に落ちる）→ スピードローダーで装填 → 手首のスナップで閉じ、トリガーガードを軸に銃を一回転 |
| 二丁拳銃 | 両方のマガジンを同時に落とし、腰のポーチへ下ろして装填 → 胸の前でX字に交差させ、スライドを同時に戻して開く |
| ライフル / SMG | 銃を傾けてマガジンを落とす → 新マガジンを挿し込みスラップ → 左手でチャージングハンドルを引く |
| ショットガン | 銃を返して1発ずつ親指で装填 → 左手でポンプを引き、銃口を跳ね上げる |
| 重火器 | 使用済みセルが蒸気とともに飛び出す → 新しいセルを押し込み掌で叩く → 充電音とともに起動 |

## 新型エネミー（MAP 1終盤〜MAP 5）

既存の敵とは違う「役割」を持つ5種。どれも専用の3Dモデル（面取り装甲＋パネルテクスチャ、旋盤・押し出し形状、発光トリム）と専用アニメーションを持ち、危険な攻撃には必ず床の予兆マーカーが出ます。

| 敵 | 役割 | 行動 |
|---|---|---|
| HALO MENDER（修復天使ドローン） | 支援・回復 | 傷ついた味方の背後に回り込み、緑の修復テザーで回復。負傷者が固まると翼を広げて範囲回復『REPAIR FIELD』。近づくと翼をたたんで逃げる。**優先撃破対象**（ボスは回復しない） |
| DUNE WYRM（掘削蛇機） | 地中奇襲 | 地上では這い回り棘を扇状に吐く → 地中へ潜って土の盛り上がりだけが迫る（無敵）→ 足元に予兆円 → 噴出して打ち上げ。噴出直後は体を立てて硬直し、全方位に棘を放つ |
| PHASE JESTER（位相道化機） | 撹乱 | お手玉をしながら周囲を回り、弧を描いて戻ってくる円月輪を投げる。2回投げるか近づかれると、回転しながら細く消えて背後・側面へ瞬間移動 |
| HIVE CARRIER（母艦蟲機） | 召喚 | 腹の扉を開いて子機 HIVE MITE を産み落とす（同時4体まで）。口から酸の塊を曲射（着弾円あり）。撃破すると最後の子機3体が飛び出す |
| MANTIS LANCER（光刃蟷螂機） | 範囲制圧 | 翅鞘を開いて溜め → 床すれすれの光線を扇状に掃射（**ジャンプで跳び越えられる**）。近づくと鎌を振り上げて扇形の斬撃 |

実装: モデルとアニメ `src/utils/eliteEnemyModels.ts`、AI `src/utils/eliteEnemyAI.ts`、予兆マーカー／掃射ビーム `src/utils/combatHazards.ts`。

## ボス戦の行動パターン

全ボスの攻撃に「①全身の予兆ポーズ（振りかぶり・屈み・照準・回転）→ ②床の予兆マーカー（中が満ちきったら着弾）→ ③着弾直前に発光部が白く明滅」の3段階の予兆が付きました。HP 66% / 33% で咆哮して衝撃波を放ち（PHASE SHIFT）、そのボスの得意技に繋げます。フェーズ2以降は護衛の新型エネミーを召喚します。

| ボス | 主な新技 |
|---|---|
| ARCH-GOLEM PRIME（MAP 1） | ROCK WAVE（叩きつけから地面を走る岩柱の列）、TITAN SWEEP（腕の大薙ぎ・ジャンプで回避）、BOULDER RAIN、子機召喚 |
| TITAN DREADNOUGHT（MAP 2） | RAIL CANNON（追尾する射線が固定された直後に貫通砲撃。フェーズ3は2連射）、ARTILLERY RAIN（着弾円への曲射）、母艦召喚 |
| ARCHON GOLGOTHA（MAP 3） | SKY DIVE（跳び上がって消え、影がプレイヤーを追跡→落下）、HEAVEN PILLAR（天からの光柱）、WING SCYTHE、道化機召喚 |
| LEVIATHAN MK-IV（MAP 4） | TENTACLE SWEEP（触腕の大薙ぎ・ジャンプで回避）、MAELSTROM（渦で引き込みながら弾幕→中心に大波）、GEYSER LINE、掘削蛇召喚 |
| HELIOS WARDEN（MAP 5） | PRISM BEAM（周囲を回転する床光線・跳び越える）、SWORD RAIN（硝子の剣が降る）、PRISM LANCE、SKY DIVE、修復天使＋蟷螂召喚 |

共通技も強化: 突進は「屈み＋進路レーン表示」後に固定方向へ突進、扇状弾幕は発射前に扇形の範囲を表示、裁きの叩きつけはフェーズ2以降に外側へ広がる衝撃波の輪（ジャンプで回避）が追加。実装は `src/utils/bossPatterns.ts`（行動）と `src/utils/bossModels.ts` の `animateBoss`（腕・触腕・砲塔・翼の予兆ポーズ）。

マップ・ステージの追加方法の目安:
`src/data/initialData.ts`（`WORLD_MAPS` と `INITIAL_MISSIONS`）→ `BattleScene3D.tsx` の `getStageTheme` / `STAGE_DIFFICULTY` → `src/utils/stageScenery*.ts`（背景）の順に追加します。MAP 4・5 の背景は `stageSceneryAbyss.ts` / `stageSceneryRelic.ts`、ボスは `bossModels.ts` にあります。

実装は `src/utils/stageScenery.ts`（空シェーダー・環境マップ・各ステージのセット）と `src/components/BattleScene3D.tsx` の `buildStageEnvironment`。
